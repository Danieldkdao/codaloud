# Codaloud UI visual prompts

Built-in Image Gen was used for three independent concept boards. Inputs were the inspected Notion workspace mock and selected high-resolution Mobbin references. Prompts request conceptual 390 × 844 native viewports; output boards are illustrative and not device-validated.

## Contextual Dock

Create realistic production-quality native mobile UI designs with clear hierarchy, strong typography and purposeful spacing for Codaloud, a voice-first coding app for iOS and Android. This is ONE design direction shown through THREE coherent screen states, not multiple concepts. Output a high-resolution landscape design board about 2400x1920 with three equal mobile app content viewports, each proportioned 390x844, side by side, small clean board title and state labels outside. No phone bodies, bezels, status bars, home indicators, browser chrome or shadows. App content only. Use current Codaloud theme: warm cream background, deep forest green foreground and primary actions, pale sage dividers and subtle surfaces. Outfit-like sans for UI and JetBrains Mono for code. Body/UI text at least equivalent 16pt, 48pt touch targets, 56pt microphone. Layout uses whitespace and separators, minimal borders, no nested cards, no decorative dashboards. Selected code pale sage. Restrained syntax coloring. Provided dark Notion workspace screenshot is a content/voice/navigation reference, NOT palette; other attached Mobbin screenshots are inspiration for grouping and sheets, not content to copy. Current date September 15 2026, avoid visible dates. Product project example 'Payments', branch 'checkout-fix', current file 'calculate-total.ts'. Code example a short calculateTotal function. Keep microphone centered in bottom voice toolbar, distinct Send button on right, mode on left, compact two-line transcript only when listening. All four workspace destinations Files, Code, Git, Agent must be accessible. Agent is an activity log, never a separate chat. No terminal, preview, pricing numbers or extra fifth destination. ONE focused user task per viewport. Match exactly the specified controls and spatial structure. Render crisp readable labels. No annotations inside app except product copy.
Direction name 'Contextual Dock'. Board labels: 'Code · listening', 'Git · review and sync', 'Git · repository menu'.
Navigation architecture: bottom voice row full width with 'Tap to send' at left, centered 56pt mic, 'Send' at right. A slim contextual toolbar immediately above it, 48pt high: Code uses previous-file arrow, next-file arrow, Undo, Redo and a labeled 'Code ▾' workspace dropdown. No permanent four-tab row. The dropdown switches among the four destinations.
Left viewport: compact top back 'Payments' and ellipsis, file row 'calculate-total.ts' with 'Saved' and '1 problem'; selected function beneath with visible code spaciously occupying middle. Bottom above toolbar a 2-line transcript 'Add a discount parameter to this function' with tiny expansion chevron. Context row arrows, undo redo, Code dropdown. Voice row Tap to send / mic / Send.
Middle viewport: top back Payments and ellipsis. Branch selector 'checkout-fix ▾'. Separate equal buttons '↓ Pull 1' and '↑ Push 2', subtle 'Checked just now'. Segmented Changes (3) / History. Three file rows with checked checkboxes and +/− counts. Primary inline button 'Commit 3 files'. Plenty blank content space. Bottom context row Search and labeled 'Git ▾'. Voice row always same mode, microphone, Send disabled.
Right viewport: same Git background dimmed. A bottom sheet opens from repository ellipsis, entitled 'Repository', close X. Grouped clear rows 'Fetch updates', 'Saved stashes', 'Publish repository', 'Open on GitHub', 'Open pull request'. Only relevant actions shown. Sheet sits above the reserved voice bar, which remains visible and operable, no sheet stack. Footer helper 'Local commits stay in this workspace'. This screen illustrates progressive disclosure of secondary Git actions. No delete button in repository menu.
